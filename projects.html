Rift - Peer-to-Peer File Transfer CLI

[November 2025]

Inspired by the inability to airdrop my friends files, I built Rift - a secure, blazing-fast, file transfer utility from scratch in Rust. Fully featured - the CLI supports multithreaded concurrent file transfers, end-to-end encryption using PAKE (password authenticated key exchange), automatic compression of folders, file chunking, and real-time progress indicators. Completely self hosted on my raspberry pi.
